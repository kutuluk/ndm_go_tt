# Реализация брокера очередей в виде веб-сервиса на Go

Я разработал веб-сервис для брокера очередей с двумя методами: **PUT** и **GET**. Сервис реализует FIFO-принцип обработки сообщений и поддерживает таймауты для GET-запросов.

## Основные компоненты

- **Broker** - главный класс, управляющий очередями
- **Queue** - класс очереди, реализующий FIFO-доступ по таймаутам и без них

## Особенности реализации

- Используется только стандартная библиотека Go
- Реализовано синхронное взаимодействие через мьютексы и условные переменные
- При опустошении очереди и при отсутствии к ней запросов она удаляется из памяти сервера, а при поступлении нового сообщения или запроса создается вновь. Это предотвращает потенциальное переполнение памяти в случае большого количества временных очередей
- Для упрошения кода для всех списков используются слайсы. При необходимости их можно переделать на двусвязные списки

## Как запустить

```bash
go run main.go [порт]
```

Если порт не указан, используется порт **8080**.
